# KRecorder
Lightweight built-in recorder for Geometry Dash 2.2.
- Press **F9** to start/stop recording
- Tiny red indicator (not captured in video)
- Async frame queue + worker thread
- Hardware encoding via Media Foundation, fallback to software H.264
- Saves to `Videos/KRecorder/KRecorder_YYYY-MM-DD_HH-MM-SS.mp4`
Configure in Geode Mod Settings -> KRecorder.
